# SmartAttendance

## Descripción

SmartAttendance es una aplicación desarrollada para la gestión de alumnos mediante una arquitectura cliente-servidor.

El sistema permite:

* Listar alumnos
* Crear alumnos
* Editar alumnos
* Eliminar alumnos

La aplicación está compuesta por un backend desarrollado en ASP.NET Core y un frontend desarrollado en React.

## Tecnologías utilizadas

### Backend

* .NET 9
* ASP.NET Core Web API
* C#
* Inyección de Dependencias
* Servicios en memoria

### Frontend

* React
* TypeScript
* Vite
* Axios
* Tailwind CSS

### Control de versiones

* Git
* GitHub

## Cómo ejecutar el Backend

1. Abrir una terminal en:

SmartAttendance/SmartAttendance

2. Ejecutar:

dotnet run

3. La API estará disponible en:

http://localhost:5210

## Cómo ejecutar el Frontend

1. Abrir una terminal en:

SmartAttendance/smartattendance-frontend

2. Instalar dependencias:

npm install

3. Ejecutar:

npm run dev

4. Abrir la URL indicada por Vite.
